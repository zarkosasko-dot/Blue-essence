Blue Essence — upload na GitHub

MORAŠ uploadati ove 3 datoteke u KORIJEN (pored starog index.html):
  index.html
  blue-essence.js
  blue-essence.css

Bez .js i .css stranica ostaje prazna.

1. Otvori https://github.com/zarkosasko-dot/Blue-essence
2. Add file → Upload files
3. Ubaci te 3 datoteke (overwrite index.html)
4. Commit changes
5. Pričekaj minutu, u Chromeu otvori:
   https://zarkosasko-dot.github.io/Blue-essence/
6. Kad vidiš app: ⋮ gore desno → skrolaj dolje → Dodaj na početni zaslon
